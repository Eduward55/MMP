My Music Place — Windows

Como chegar aqui (Linux):

rm -rf ~/MMP && git clone https://github.com/Eduward55/MMP.git ~/MMP && cd ~/MMP/entrega && bash juntar.sh

1. O comando acima junta os pedaços (~118 MB).
2. Extraia MyMusicPlace-Windows.zip (a pasta inteira).
3. No Windows, abra "My Music Place.exe" de dentro da pasta extraída.

O .exe é para mandar a outras pessoas no Windows.
